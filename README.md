# Client Approval Panel

## Phase 1 setup

1. Start Apache and MySQL in XAMPP.
2. Open `http://localhost/phpmyadmin` and import `database/schema.sql`.
3. Update database credentials in `config.php` if your MySQL password is not empty.
4. Create the first admin user in phpMyAdmin using a password hash generated by:

```php
<?php echo password_hash('ChangeThisPassword', PASSWORD_DEFAULT); ?>
```

Use the generated value in an insert such as:

```sql
INSERT INTO users (name, email, password, role)
VALUES ('Administrator', 'admin@example.com', 'PASTE_HASH_HERE', 'admin');
```

5. Open `http://localhost/client-approval-panel/`.

## Phase 2 setup

If the Phase 1 schema is already installed, import `database/migration_phase2.sql` in phpMyAdmin first. If you have not imported the schema yet, use the updated `database/schema.sql` instead.

After signing in as an admin, use the dashboard links to manage users and clients. Deactivation is used instead of deletion so existing content and history are preserved.

## Phases 3-6 setup

Phases 3-6 use the existing tables already included in `database/schema.sql`; no additional database import is required. When development is complete, import only this final schema into the cPanel MySQL database.

Phase 5 adds client approval, change requests, comments, and AJAX status updates. Phase 6 adds employee content status lists and the admin overview dashboard.

Phases 7-8 add attendance, leave requests, tasks, activity logs, and monthly performance reports. These tables are included in the final schema; do not import the phase migration reference files for a new installation.

Phase 9 adds content revision history, carousel drag-reordering, CSV performance export, and optional email notifications. Set `MAIL_FROM` in `config.php` to enable notifications on a cPanel mail-enabled host.

Finance F6-F10 adds cash flow, finance dashboard, Chart.js KPI charts, finance CSV reports, security hardening guidance, and cPanel deployment checks. See SECURITY_DEPLOYMENT.md.
